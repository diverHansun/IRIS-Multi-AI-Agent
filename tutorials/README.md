## 学习路径建议

### 新手开发者
1. 先阅读 **软件测试入门教程**，理解测试的重要性
2. 学习 **LangChain框架教程**，掌握AI应用开发基础
3. 结合项目实际代码进行实践

### 有经验的开发者
1. 可直接查阅对应技术的教程文档
2. 结合项目的测试框架进行实际应用
3. 参与贡献更多教程内容

## 如何使用教程

- 每个教程都是独立的Markdown文档，可以单独阅读
- 教程中的示例代码都基于本项目的实际代码
- 建议边阅读边实践，加深理解
