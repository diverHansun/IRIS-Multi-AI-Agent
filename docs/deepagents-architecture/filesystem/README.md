## 技术栈

**虚拟文件系统：**
- LangGraph State Management
- LangGraph Store（长期记忆）
- Python 标准库

**真实文件系统：**
- Python pathlib
- Python glob
- Python re（正则表达式）
- 参考 Claude Code 的设计

---

## 关键概念

### 虚拟文件系统

完全内存化的文件存储系统，与宿主机文件系统隔离，用于 Agent 的内部工作空间和长期记忆。

### 真实文件系统

只读访问宿主机文件系统的工具集，通过严格的权限控制确保安全，用于获取外部信息。

### 双文件系统

同时支持虚拟和真实文件系统，各司其职，互不干扰。
